TurboScan is an AI-powered predictive maintenance platform developed using the NASA C-MAPSS turbofan engine dataset. The system predicts equipment failures and estimates Remaining Useful Life (RUL) to support proactive maintenance planning.

**Key Contributions**

- Developed LSTM-based models for Remaining Useful Life prediction using time-series sensor data.
- Built XGBoost classification models for failure prediction and maintenance prioritization.
- Implemented DBSCAN-based anomaly detection for identifying abnormal equipment behavior.
- Designed equipment health monitoring dashboards for maintenance decision support.
- Applied feature engineering, sequence generation, and model evaluation techniques to improve predictive performance.
